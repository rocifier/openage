# Proposal

## Why

Matches currently have no winner. Requested by Dougie on 2026-10-27, written up
here so it is on the roadmap.

## What Changes

- **Hunter wins** when every Builder is dead.
- **Builders win** when the 45-minute match timer runs out.
- When a Builder dies, all of that player's towers collapse.
- "Hunter wins" and "Builders win" end screens for every player.
- Typical matches have 7 Builders against 1 Hunter.

## Capabilities

### New Capabilities

- `fvd-match-end`: win conditions, timer and end screens.

## Status

Proposed (Dougie, 2026-10-27). Not implemented.
